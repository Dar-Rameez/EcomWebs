# EcomWebs 🛍️

A simple and responsive e-commerce website built using **Vanilla JavaScript, HTML, and CSS**, with Vite for development and building.

## 📌 About the Project

EcomWebs is a small e-commerce web development project created to practice front-end development and build an online shopping interface.

## ✨ Features

- Responsive user interface
- Product display and shopping interface
- Interactive functionality using Vanilla JavaScript
- Custom styling with CSS
- Fast development environment powered by Vite

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) before running the project.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Dar-Rameez/ecomwebs.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ecomwebs
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
